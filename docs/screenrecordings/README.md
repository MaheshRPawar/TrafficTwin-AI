# Prototype Screen Recordings

This directory documents the live SUMO + Python/TraCI simulation screen recordings:

1. **`Emergency-Green-Signal-SUMO-Simulation.mp4`**
   - Shows the emergency vehicle signal preemption mechanism in action.
   - Demonstrates emergency vehicle `emerg_1` approaching junction `J6` on corridor `E5`.
   - Captures the Python TraCI controller dynamically preempting the active signal schedule, granting green priority (`rGGr`), and automatically resetting to standard cycle once the corridor is cleared.

2. **`Locate-Vehicles-and-Junctions-SUMO-Simulation.mp4`**
   - Demonstrates real-time vehicle positioning, edge tracking, and intersection monitoring.
